# 5. API — SlotSaver REST API

Base URL: `{API_URL}/api/v1`. JSON in and out. Auth via HttpOnly session cookie `ss_session`.

## Conventions
- **Success:** `{ "data": ..., "meta"?: { "page", "pageSize", "total" } }`
- **Error:** `{ "error": { "code": "VALIDATION_ERROR", "message": "...", "details"?: [...], "requestId": "..." } }`
- **Status codes:** 200 OK, 201 Created, 204 No Content, 400 validation, 401 unauthenticated, 403 forbidden, 404 not found (also used for other-tenant resources), 409 conflict (slot taken), 410 gone (expired link/offer), 429 rate limited, 500 generic.
- **Mutations** require header `X-Requested-With: SlotSaver` and an allowed `Origin`.
- **Idempotency:** booking, acceptance, and cancellation endpoints accept header `Idempotency-Key`.
- **Pagination:** `?page=1&pageSize=20` (max 100). **Sort/filter:** documented per endpoint.
- **Tenant:** org-scoped routes use `/orgs/:orgId/...`; the server checks membership on every call.

## Availability (public for booking pages)
`GET /public/businesses/:businessSlug/services/:serviceSlug/availability?from=YYYY-MM-DD&to=YYYY-MM-DD&staffId=` returns slots grouped by day in the organization timezone:
```json
{ "data": { "timezone": "Asia/Kolkata", "days": [ { "date": "2026-10-20", "slots": [ { "startAt": "2026-10-20T04:30:00.000Z", "staffId": "...", "staffName": "..." } ] } ] } }
```

## Appointments
| Method | Path | Role |
|---|---|---|
| GET | `/orgs/:orgId/appointments` | filters: `from`, `to`, `serviceId`, `staffId`, `status`, `q` |
| POST | `/orgs/:orgId/appointments` | owner, admin, staff (own only) |
| GET | `/orgs/:orgId/appointments/:id` | scoped |
| PATCH | `/orgs/:orgId/appointments/:id` | reschedule / status (completed, no_show) |
| POST | `/orgs/:orgId/appointments/:id/cancel` | cancels and triggers recovery |

Status transitions: `requested → confirmed`, `confirmed → completed | no_show | cancelled`, `requested → cancelled`. Anything else returns 409.

## Notifications and reminders
`GET /orgs/:orgId/notifications` (delivery history), `GET /orgs/:orgId/reminder-settings`, `PUT /orgs/:orgId/reminder-settings`, `GET /orgs/:orgId/notifications/templates/:type/preview`.

## Analytics
`GET /orgs/:orgId/dashboard?from&to`, `GET /orgs/:orgId/analytics?from&to&group=day|week|month`, `GET /orgs/:orgId/analytics/export.csv` (owner, admin).

## Audit
`GET /orgs/:orgId/audit-logs?from&to&action&page` (owner, admin). No write, update, or delete endpoints exist.

## Health
`GET /health` (liveness), `GET /health/ready` (checks Mongo connection and queue status). Public, no internal details.

## Rate limits (per IP unless noted; all configurable)
| Scope | Default | Variables |
|---|---|---|
| login | 10 per 15 min per IP; plus backoff per email after 3 failures (2 s doubling to 15 min) | `RATE_LIMIT_LOGIN_MAX`, `RATE_LIMIT_LOGIN_WINDOW_MINUTES`, `LOGIN_BACKOFF_*` |
| signup | 5 per hour | `RATE_LIMIT_SIGNUP_*` |
| password reset and resend verification | 5 per hour | `RATE_LIMIT_PASSWORD_*` |
| public booking | 20 per 15 min | `RATE_LIMIT_BOOKING_*` |
| guest and offer actions | 30 per 15 min | `RATE_LIMIT_GUEST_*` |
| invitations | 20 per hour | `RATE_LIMIT_INVITE_*` |
| general API | 300 per 15 min | `RATE_LIMIT_GENERAL_MAX` |

A blocked request returns `429` with code `RATE_LIMITED`. Login blocks also set `Retry-After` in seconds.

## OpenAPI
The machine-readable spec is served at `/api/docs` (Swagger UI) and `/api/openapi.json`, generated from this document's route definitions.

## Implemented in the current build (added after the initial contract)
| Method | Path | Notes |
|---|---|---|
| GET | `/auth/export` | Personal data export (profile, memberships, actions). Never includes hashes, tokens, or session secrets. |
| DELETE | `/auth/account` | Body `{ password }`. Refused with 409 `OWNER_HAS_ORGANIZATION` while an owner has a live organization. Anonymizes the user and revokes sessions. |
| DELETE | `/orgs/:orgId` | Owner only. Body `{ confirmName }` must match the organization name exactly. Archives the organization: public pages return 404 and member routes return 404. |
| GET | `/openapi.json` | Partial OpenAPI 3.0 document (`x-status: partial`). Lists every route group; schemas are not complete. |
| POST | `/public/guest/appointments/:token/reschedule` | Returns the new manage token in `manageToken` to the caller who proved possession of the old link. The old link stops working. |

Public booking responses never include a manage token. The link is only sent by email.

Analytics definitions (computed in code): bookings exclude rolled-back records; cancellation rate is cancelled ÷ bookings; no-show rate is no-shows ÷ (completed + no-shows); recovered bookings are appointments created from an accepted waitlist offer and not cancelled; estimated recovered value is booked value, not collected revenue; offer acceptance is accepted ÷ (accepted + declined + expired); staff utilization does not yet subtract closures.
