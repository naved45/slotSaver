## Assumptions log
- Auth: session cookies (not JWT in localStorage).
- Queue: MongoDB-backed job store by default; BullMQ when `REDIS_URL` is set.
- Email: SMTP via Nodemailer; no SMTP config → `logged_dev` preview mode.
- Payments: not implemented.
- Pricing tiers are proposals to validate.

## Decision log
Record each decision here with date, reason, and the doc it changed. Example: "Double-booking guard uses a unique partial index plus a service-layer overlap check; transactions used when a replica set is detected."

- Bundle: main chunk 534 kB; analytics lazy-loaded.
- Screen reader and mobile viewport testing not performed.
