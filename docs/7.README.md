# 7. README — SlotSaver

**Smart Appointment Scheduling for Your Business.** Get more bookings. Less no-shows.

SlotSaver is a scheduling and cancellation-recovery app for small service businesses. When an appointment is cancelled, SlotSaver offers the freed time to eligible customers on the waitlist, one at a time, with a safe claim so the same slot is never double-booked.

## What is in this repo
- `frontend/` — React (Vite) marketing site and business app.
- `backend/` — Express + MongoDB API, background worker, tests.
- `docs/` — the 15 project documents (this folder).
- `.github/workflows/ci.yml` — lint, test, and build on push.

## Quick start
See `SETUP.md` for exact commands. Short version:
```bash
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
npm install --prefix backend && npm install --prefix frontend
npm run seed --prefix backend        # fictional demo data
npm run dev --prefix backend         # API on :4000  (MONGO_TTL_INDEXES=off only for FerretDB)
npm run dev --prefix frontend        # app on :5173
```

## Status
The core application is built and tested: backend (94 tests), frontend (13 tests), a headless-browser pass over the main flows, lint, builds, and dependency audit. See `TESTING_QA.md` for the recorded results and `PROJECT_IMPLEMENTATION.md` for known limitations. It has not been deployed or tested against real MongoDB, SMTP, or hosting.
