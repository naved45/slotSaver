# 9. SETUP — Local Development

## Requirements
- Node.js 20 LTS or 22 (tested on 22.x).
- npm 10+.
- MongoDB 6+ running locally, or a MongoDB Atlas connection string.
- Redis 7+ (optional, only if using BullMQ).
- Git.

## 1. Clone and install
```bash
git clone <your-repo-url> slotsaver
cd slotsaver
npm install --prefix backend
npm install --prefix frontend
```

## 2. Environment files
```bash
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
```
Edit `backend/.env`:
```env
NODE_ENV=development
PORT=4000
MONGODB_URI=mongodb://127.0.0.1:27017/slotsaver
MONGODB_TEST_URI=mongodb://127.0.0.1:27017/slotsaver_test
APP_ORIGIN=http://localhost:5173
SESSION_TTL_DAYS=14
SESSION_COOKIE_SECURE=false
# Optional — leave empty for dev email preview
SMTP_HOST=
SMTP_PORT=587
SMTP_USER=
SMTP_PASS=
EMAIL_FROM="SlotSaver <no-reply@example.com>"
# Optional — leave empty to use the MongoDB job store
REDIS_URL=
```
Edit `frontend/.env`:
```env
VITE_API_URL=http://localhost:4000
```

## 3. Start MongoDB
Local with Docker:
```bash
docker run -d --name slotsaver-mongo -p 27017:27017 mongo:7
```
Transactions require a replica set. The default local setup works without transactions; the code uses a fallback guard. To enable transactions locally:
```bash
docker run -d --name slotsaver-mongo -p 27017:27017 mongo:7 --replSet rs0
docker exec slotsaver-mongo mongosh --eval "rs.initiate()"
```

## 4. Seed demo data (fictional)
```bash
npm run seed --prefix backend
```
Creates demo owner `owner@example.com` with a placeholder password printed by the script. Change it after first login.

## 5. Run
Two terminals:
```bash
npm run dev --prefix backend    # http://localhost:4000
npm run dev --prefix frontend   # http://localhost:5173
```
Worker (reminders and offers), third terminal:
```bash
npm run worker --prefix backend
```

## 6. Verify
```bash
curl http://localhost:4000/health
npm test --prefix backend
npm test --prefix frontend
npm run lint --prefix backend && npm run lint --prefix frontend
npm run build --prefix frontend
```
